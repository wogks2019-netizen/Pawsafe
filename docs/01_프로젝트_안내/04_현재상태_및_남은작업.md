# 04. 현재상태 및 남은 작업

## 완료된 부분

- 송파구 보행망 3,797개 Edge 구성
- 건물·가로수·기상·포장재 전처리
- 24시간 Edge×시간 피처 91,128행 생성
- 건물·가로수 그림자율 계산
- 직사광선·누적일사·열저장 Proxy 계산
- K-means/GMM 비교와 K-means k=2 선택
- 연속형 Heat Cost 생성
- Fast·Cool 임시 경로 생성
- 잠실 IoT 환경별 지면온도 방향성 검증
- 앱용 GeoJSON 생성

## 우선순위 높은 남은 작업

1. 포장재 데이터가 연결된 구간에서 새 출발·도착지 선정
2. 연속형 Heat Cost를 메인 파이프라인에 통합
3. IoT 관측 위치를 Edge와 연결하거나 방향성 검증의 한계를 명확히 표기
4. 경로 구간별 `pavement_known` 및 데이터 확보율 출력
5. 출발·도착·시간 입력형 앱과 연결
6. README·config·발표자료의 가중치와 용어 통일

## 현재 결과에서 반드시 밝힐 한계

- 포장재 확인 Edge는 784개로 전체의 약 20.6%입니다.
- 현재 임시 경로는 포장재 확인 구간이 약 46~50%입니다.
- IoT 검증은 환경별 평균 비교이며 Edge별 예측 정확도 검증은 아닙니다.
- Heat Cost는 상대 점수이며 실제 노면온도나 절대 안전 판정이 아닙니다.
