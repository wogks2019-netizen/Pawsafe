# 02. 코드 실행순서

모든 명령은 이 `PawSafe` 폴더에서 실행합니다.

## 최초 한 번: 환경 설치

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 실행 순서

| 순서 | 파일 | 역할 | 주요 결과 |
|---:|---|---|---|
| 0 | `scripts/00_실행환경_확인.py` | 필수 데이터·패키지 확인 | 누락파일 안내 |
| 1 | `scripts/01_전체_전처리_군집화_실행.py` | 전처리·그림자·피처·군집화 | `data/processed/*`, 기본 Heat Map |
| 2 | `scripts/02_포장재_보유구간_확인.py` | 포장재 보유 Edge와 연결성 확인 | 포장재 연결망 GeoJSON |
| 3 | `scripts/03_연속형_HeatCost_생성.py` | 15시 연속 Heat Cost 생성 | 연속 Heat Map |
| 4 | `scripts/04_추천경로_생성.py` | Fast·Cool 경로 계산 | 경로·지표 파일 |
| 5 | `scripts/05_IoT_지면온도_검증.py` | 잠실 환경별 온도 방향성 확인 | 표·차트 |
| 6 | `scripts/06_앱용_데이터_생성.py` | 앱에서 읽기 쉬운 결과 생성 | `app_*.geojson` |

실행 예시:

```powershell
python scripts/00_실행환경_확인.py
python scripts/01_전체_전처리_군집화_실행.py
python scripts/02_포장재_보유구간_확인.py
python scripts/03_연속형_HeatCost_생성.py
python scripts/04_추천경로_생성.py
python scripts/05_IoT_지면온도_검증.py
python scripts/06_앱용_데이터_생성.py
```

## 핵심 코드 위치

| 파일 | 쉬운 설명 |
|---|---|
| `src/pawsafe/preprocess.py` | 원본 데이터를 불러와 Edge에 연결 |
| `src/pawsafe/shadow.py` | 건물·가로수 그림자 계산 |
| `src/pawsafe/features.py` | 직사광선·누적일사·열저장 피처 계산 |
| `src/pawsafe/clustering.py` | K-means/GMM 비교와 군집 Heat Cost |
| `src/pawsafe/routing.py` | 그래프 구성과 Dijkstra 경로추천 |
| `src/pawsafe/pipeline.py` | 위 과정을 순서대로 호출 |

`scripts/` 안의 실행 파일은 어느 폴더에서 실행해도 프로젝트 루트를 기준으로 동작합니다. `src/pawsafe/`의 파일명은 서로 import하므로 임의로 변경하지 않습니다.
