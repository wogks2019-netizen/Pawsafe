# 핵심 코드 설명

- `preprocess.py`: 원본 불러오기, 좌표계 통일, 포장재 연결, 결측 처리
- `shadow.py`: 태양 위치와 건물·가로수 그림자 계산
- `features.py`: 직사광선·누적일사·열저장 피처 생성
- `clustering.py`: K-means/GMM 비교, 군집 해석, Heat Cost 생성
- `routing.py`: Node·Edge 그래프와 Dijkstra 경로추천
- `pipeline.py`: 전체 과정을 순서대로 호출
- `utils.py`: 설정·CSV 인코딩·공통 함수

이 파일들은 서로 import하므로 파일명을 변경하지 않습니다.
